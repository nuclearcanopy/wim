# audit, november 2026

Whole-repo audit at `77839e4`: security, reliability, performance, ui, ux,
packaging, tests. Findings that were cheap and safe to fix are fixed on
branch `audit/2026-11`; the rest are listed below with severity so none
is silently dropped. This sits beside `performance-audit-roadmap.md`, which
stays the checklist for the larger measured performance work.

## method

- baseline: `cargo fmt --check`, `clippy --all-targets -D warnings`,
  `cargo test --locked` all clean at `77839e4` (1609 tests).
- three read-only source reviews (security, reliability, ui/ux), each
  finding checked against the code before acting on it.
- `cargo audit`, `cargo machete`.
- pty harness (python `pty` + `pyte`) for terminal sizes, SIGTERM,
  idle redraw cost and startup; release builds of base and branch.
- live run against a real Navidrome server and a TorBox account, with
  credentials read only from files and every output scrubbed. Read-only
  commands and playback only; nothing was starred, added or deleted.

## measured, no change needed

- startup, release, pty: first screen wim 3.1ms -> 2.9ms, shellswim
  2.6ms -> 2.7ms (noise); no regression.
- live Navidrome: 507 songs indexed from cache in ~0.1s; a stream opens
  through the media relay and the scrubber advances; TorBox status, list and
  search work.
- credentials: none found in the cache, state or config written during live
  runs.

## open, by severity

P1
- A2: `f` is both "skip" and the video fullscreen reflex; fullscreen wins,
  so skip is dead during video. Needs a key decision.
- A3: `W`, `T`, `J/K`, `ctrl+x`, F11 are hard-wired, absent from help and
  from `RESERVED_KEYS`, so a user can bind onto a dead key.
- A4: onboarding "add server" indexes the whole catalog on the ui thread
  (now bounded by the new timeouts, still blocks).
- A5: dark background and truecolor are assumed; no `COLORTERM`/`TERM`
  fallback or light-theme handling.
- F8: OpenSubtitles download link and Musixmatch tracking url are fetched
  with default redirects and no address check.

P2
- M3: no mpv crash detection or respawn; a dead mpv leaves stale ui state.
- M4: a timed-out `loadfile` can still run in mpv and desync the queue mirror.
- C2: `TrackResolver` ticket order can wedge if one worker stalls.
- C4-C6: cache lock held across disk io; relay tunnel has no idle timeout;
  per-action thread creation is unbounded (tracked in the perf roadmap).
- P4: concurrent wim processes can overwrite each other's index/state.
- B1: `R` in the keybinds menu resets everything without confirmation.
- B2/B5/B9: `NO_COLOR` does not reach album art; no reduced-motion option;
  error toasts vanish after at most 6s with no history.
- B6/B7: per-frame allocation in lyrics, help and browse; `draw` runs
  unconditionally on every loop iteration (ratatui diffs, so bytes are low).
- B12: shellswim and a few views use stock ratatui widgets against the
  repo's own text-measurement rule.
- B14/B15: mouse cannot dismiss modals; help text drifts from behaviour
  in resize/scrub/move modes and workspace keys.
- F7 (rest): `into_json` bodies in lyrics/torbox/opensubtitles are uncapped.
- F6: the relay failing to start is silent for local Navidrome playback
  (Watch is already gated on it).
- F13/F14: trusted-origin DNS answers are unchecked; relay has no token.
- deps: `lru 0.12.5` (RUSTSEC-2026-0002, -0253, unsound, via ratatui 0.29)
  and `paste` (unmaintained). Needs a ratatui bump.

P3
- M7/M8/M9/M10, P5-P7, R1, F10, F12, F15-F20, C1-C7 of the ui review
  (doc drift, cli polish, shellswim parity, ambiguous-width glyphs).
- the `playback_path` directory sweep and `catalogs/` files are 0644.
- the terminate handlers are installed with the terminal guard, so a SIGTERM
  during very early startup or a long blocking call is only seen on the next
  loop pass (systemd would escalate to SIGKILL).
- test coverage and mutation testing were not run; `cargo udeps`, `deny`,
  `miri` and `llvm-cov` were not run.

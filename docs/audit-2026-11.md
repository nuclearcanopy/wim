# audit, november 2026

Whole-repo audit at `77839e4`: security, reliability, performance, ui, ux,
packaging, tests. Findings that were cheap and safe to fix are fixed on
branch `audit/2026-11`; the rest are listed below with severity so none
is silently dropped. This sits beside `performance-audit-roadmap.md`, which
stays the checklist for the larger measured performance work.

## method

- baseline: `cargo fmt --check`, `clippy --all-targets -D warnings`,
  `cargo test --locked` all clean at `77839e4` (1609 tests).
- three read-only source reviews (security, reliability, ui/ux), each
  finding checked against the code before acting on it.
- `cargo audit`, `cargo machete`.
- pty harness (python `pty` + `pyte`) for terminal sizes, SIGTERM,
  idle redraw cost and startup; release builds of base and branch.
- live run against a real Navidrome server and a TorBox account, with
  credentials read only from files and every output scrubbed. Read-only
  commands and playback only; nothing was starred, added or deleted.

## measured, not changed

- B6/B7 (per-frame allocation, unconditional `draw`): with nothing animating
  the whole process uses 0.03s cpu per 10s and writes 2.5 KB (ratatui diffs
  the frame), so a dirty-flag or cached wrap is not worth the risk.
- M9 (blocking ipc on the ui thread, 10s worst case): only reachable with a
  wedged mpv, which M3 now reports and the 2s write timeout bounds on the
  write side.

## still open

- M8: a `playlist-pos` event queued before a queue rewrite can resolve against
  the new list (needs a natural advance racing a "play now").
- P4 is mitigated, not solved: two wims can still overwrite each other's
  state; the second one says so.
- P7: state files have no version field; the on-disk shapes are pinned by
  tests, add the field with the first schema change.
- F20: the downloaded subtitle sidecar is written with `fs::write` next to
  the video (follows a symlink an attacker with write access to the media
  directory planted).
- `paste` (RUSTSEC-2024-0436) is unmaintained and transitive.
- the nav manager still pings every server on open (bounded by the 10s
  connect timeout, runs in parallel).
